# bluetui

`bluetui` — терминальный интерфейс для управления Bluetooth на Linux. Приложение показывает адаптеры, уже спаренные устройства и новые найденные устройства, а также поддерживает операции подключения, доверия, избранного и переименования прямо из TUI.

## ✨ Особенности

- Работает поверх BlueZ и получает данные через `bluer`.
- Показывает список адаптеров, спаренных и новых устройств.
- Позволяет включать и выключать питание, discoverable и pairing режимы адаптера.
- Поддерживает connect/disconnect, trust/untrust, favorite/unfavorite и rename для устройств.
- Обрабатывает запросы PIN-кода, passkey и подтверждения спаривания.
- Настраивается через `config.toml` и поддерживает пользовательские клавиши.

## 🚀 Быстрый старт

### Требования

- Linux
- установленный BlueZ
- по желанию Nerd Font для корректного отображения иконок

### Сборка из исходников

```bash
cargo build --release
./target/release/bluetui
```

### Установка через Cargo

```bash
cargo install --path .
bluetui
```

### Пользовательский конфиг

```bash
bluetui -c /path/to/config.toml
```

## 📁 Структура проекта

- `src/main.rs` — запуск TUI, событийного цикла и проверки `rfkill`.
- `src/cli.rs` — CLI-аргументы.
- `src/config.rs` — загрузка и валидация конфигурации.
- `src/app.rs` — состояние приложения.
- `src/bluetooth.rs` — работа с адаптерами и устройствами.
- `src/ui.rs` — разметка интерфейса.
- `src/help.rs` — подсказки по горячим клавишам.
- `src/requests/` — формы и обработка запросов подтверждения и паролей.

## 🛠 Использование

Базовые клавиши:

- `Tab` или `l` — перейти к следующему блоку.
- `Shift+Tab` или `h` — перейти к предыдущему блоку.
- `j` / `Down` и `k` / `Up` — перемещение по спискам.
- `s` — включить или выключить сканирование.
- `q` или `Ctrl+C` — выход.

Клавиши адаптера:

- `p` — переключить pairing.
- `o` — включить или выключить питание.
- `d` — переключить discoverable.

Клавиши устройств:

- `Enter` или `Space` — pair/connect/disconnect в зависимости от контекста.
- `u` — unpair.
- `t` — trust/untrust.
- `f` — favorite/unfavorite.
- `e` — изменить alias устройства.

Путь по умолчанию для конфигурации:

```text
$HOME/.config/bluetui/config.toml
```
